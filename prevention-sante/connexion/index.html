Code de vérification

Votre compte donne accès aux dossiers de plusieurs personnes. Un mot de passe seul ne suffit donc pas : saisissez le code à six chiffres de votre application d’authentification.

Le code change toutes les trente secondes, et chaque code ne sert qu’une fois. Si vous venez de l’utiliser, attendez le suivant.

Activer la double vérification

Votre rôle l’exige. Enregistrez la clé ci-dessous dans une application d’authentification, puis confirmez avec le code qu’elle affiche.

Cette clé ne sera plus affichée après cette étape. Toute application compatible convient : elles suivent la même norme.

Vos codes de secours

Notez-les et rangez-les ailleurs que sur votre téléphone. Si vous perdez votre application d’authentification, ils sont le seul moyen de vous reconnecter sans intervention technique.

Chaque code ne sert qu’une fois. Ils ne seront plus jamais affichés : si vous les perdez, il faudra en regénérer depuis votre espace.

Mot de passe oublié
